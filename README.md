# Ерудит Плюс — новий сайт

Многостраничный сайт репетиторского центра «Ерудит Плюс» на **React + Vite + Tailwind CSS** с моушн-графикой.

## Как открыть сайт

Нужен установленный **Node.js 18+** (https://nodejs.org — кнопка LTS).

**Windows:** дважды кликните `start-windows.bat`
**macOS / Linux:** в терминале в этой папке: `sh start-mac-linux.sh`

Или вручную:

```bash
npm install      # один раз — скачать зависимости
npm run dev      # запустить сайт → откроется http://localhost:5173
```

## Бесплатно на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New**), тип **Public**.
2. **Add file → Upload files** — перетащите всё содержимое папки проекта, **кроме `node_modules` и `dist`**. Папку `.github` перетащить обязательно. Нажмите **Commit changes**.
3. **Settings → Pages → Source: GitHub Actions**.
4. Во вкладке **Actions** дождитесь зелёной галочки (2–3 минуты).
5. Сайт: `https://ВАШ-НИК.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`

Если назвать репозиторий `ВАШ-НИК.github.io`, сайт будет на `https://ВАШ-НИК.github.io/`.

**Свой домен** (например erudit-plus.com.ua): создайте файл `public/CNAME` с одной строкой — доменом, у регистратора домена добавьте DNS-запись CNAME на `ВАШ-НИК.github.io`, затем укажите домен в **Settings → Pages → Custom domain**.

## Как выложить на хостинг

```bash
npm run build    # готовый сайт появится в папке dist/
```

Содержимое `dist/` загрузите на любой хостинг. Для Netlify (`_redirects`), Vercel (`vercel.json`) и Apache (`.htaccess`) настройки адресов уже включены — страницы вида `/predmety/fizyka` будут открываться напрямую.

## Что заменить перед запуском

| Файл | Что там |
|---|---|
| `src/config/site.ts` | телефоны, адрес, график, `formEndpoint` для формы |
| `src/data/prices.ts` | **цены — сейчас ориентировочные, поставьте реальные** |
| `src/data/reviews.ts` | **отзывы — сейчас макеты с пометкой «зразок»; перенесите реальные со старого сайта** |
| `src/data/subjects.ts` | тексты и темы по предметам |
| `src/data/posts.ts` | статьи блога |

**Форма записи.** Пока `formEndpoint` пустой, после отправки форма показывает благодарность и кнопки звонка. Чтобы заявки приходили на почту, зарегистрируйтесь на Formspree/Getform и вставьте адрес в `formEndpoint`.

## Моушн-графика

- Интро-заставка со счётчиком 0→100% (один раз за сессию)
- Кастомный курсор с инерцией, магнитные кнопки
- Интерактивное «созвездие знаний» на canvas — реагирует на мышь
- Вращающаяся «планетарная система» предметов (каждый символ — ссылка)
- Заголовки, вырастающие по словам; меняющиеся слова-барабаны
- Шторка-переход между страницами
- Горизонтальная прокрутка этапов обучения, закреплённая на экране
- Манифест, слова которого «загораются» при прокрутке
- 3D-наклон карточек и подсветка-прожектор под курсором
- Уникальная SVG-анимация для каждого предмета (синусоида, атом, ДНК, молекула, таймлайн…)
- Мега-меню, полноэкранное мобильное меню, бесконечные бегущие строки
- Финальная CTA-секция с HLS-видео, liquid glass и футером на каждой странице
- Учитывается системная настройка «уменьшить движение»

## Структура

```
src/
  config/       настройки центра и меню
  data/         предметы, цены, отзывы, статьи, FAQ
  hooks/        анимационные хуки (появление, прокрутка, магнит, наклон, счётчик)
  components/
    layout/     шапка, мобильное меню, курсор, заставка, переходы, прогресс
    sections/   секции страниц, включая CtaFooter (HLS-видео)
    ui/         кнопки, анимированный текст, карточки, аккордеон
    visuals/    canvas-частицы, орбиты, SVG-анимации предметов
  pages/        все страницы сайта
```
